How to update your website

Edit any book details below, then follow these steps:

  1. Click Export books.json (top right) — a file downloads
  2. Log into Hostinger File Manager → open public_html
  3. Delete the old books.json and upload the new one
  4. Your website updates instantly ✓
💡 Tip: Bookmark this page (admin-books.html) on your website so you can always access it. The file is only accessible to people who know the URL — it doesn't need a password since it only edits a local download.
